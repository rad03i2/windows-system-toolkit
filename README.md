# Windows System Toolkit

A beginner-friendly toolkit for reading system information, checking storage, and producing local reports on Windows.

## Tools

- PowerShell system report
- Disk usage scanner concept
- Safe cleanup preview script
- C# system information model

## Stack

`PowerShell` · `C#` · `Windows` · `CLI`

## Safe by design

Cleanup scripts run in preview mode first. They print what could be removed instead of deleting files immediately.
